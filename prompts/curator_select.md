## Задача

Выбери статьи для следующего круга.

- Если экзамен сдан: 2 по текущей теме (добить дыры) + 4 по смежной,
  и смежная становится активной.
- Если провален: 4 по текущей (закрыть провалы) + 2 по смежной,
  тема остаётся.
- Бери **только id из библиотеки выше**. Ничего не придумывай.
- Не выдавай то, что уже выдавалось.
- Для каждой статьи — одна строка, зачем именно она. Это пойдёт
  в публичный комментарий.
- Если подходящих статей в библиотеке не хватает, так и скажи
  в поле shortage — это сигнал автору пополнить библиотеку.

{

  "next_topic": "..." | null,
  "topic_switch": true|false,
  "shortage": "..." | null,
  "public_comment": "..."
}
